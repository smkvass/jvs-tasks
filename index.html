Theory

Global scope

A variable in global scope can be accessed from anywhere in the program.

Function scope

A variable in function scope can only be accessed inside the function.

Block scope

A variable in block scope can only be accessed inside a block, such as an if statement.

Difference between var, let, and const

var, let, and const: var has function scope, while let and const have block scope. let can be changed, but const cannot be reassigned.
